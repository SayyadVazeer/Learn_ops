Task API

A small API for practicing Python and Docker.

Use the endpoints below to check the service and manage tasks. Examples use curl.exe in PowerShell.

GET/health

Check whether the service is running. No request body is needed.

curl.exe http://localhost:8000/health

Success response (200):

{"status":"ok"}

GET/tasks

Get all tasks. A new task list is empty until you create a task.

curl.exe http://localhost:8000/tasks

Success response (200):

[{"id":1,"title":"Learn Docker","completed":false}]

POST/tasks

Create a task by sending a JSON object with a non-empty title.

curl.exe -X POST http://localhost:8000/tasks `
  -H "Content-Type: application/json" `
  -d '{\"title\":\"Learn Docker\"}'

Success response (201) includes the new task. Missing or blank titles return 400.

{"id":1,"title":"Learn Docker","completed":false}

DELETE/tasks/<id>

Delete a task by its numeric ID. Replace 1 with the ID you want to delete.

curl.exe -X DELETE http://localhost:8000/tasks/1

Success response is 204 with no body. An ID that does not exist returns 404.

Note: Tasks are stored in memory and will be cleared when the app restarts.
