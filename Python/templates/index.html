    API guide

    The page uses these same endpoints, which you can also try with curl.exe in PowerShell.

    GET/health

    Check that the service is running.

    curl.exe http://localhost:8000/health

    Returns 200: {"status":"ok"}

    GET/tasks

    List all tasks.

    curl.exe http://localhost:8000/tasks

    POST/tasks

    Create a task with a non-empty title. Missing or blank titles return 400.

    curl.exe -X POST http://localhost:8000/tasks `
  -H "Content-Type: application/json" `
  -d '{\"title\":\"Learn Docker\"}'

    DELETE/tasks/<id>

    Delete a task by its numeric ID. A missing ID returns 404.

    curl.exe -X DELETE http://localhost:8000/tasks/1
